## Engineering principles

- Automate repeatable work.
- Prefer immutable artifacts and explicit versioning.
- Treat rollback and observability as deployment requirements.
- Keep credentials out of source control.
- Document decisions, failure modes and verification steps.

## Current focus

Building reusable delivery and infrastructure patterns that are understandable, testable and safe to operate.
